# **App Name**: ElevateFit

## Core Features:

- Trainer Dashboard & Student Management: Allow personal trainers to register, create, and manage individual student profiles including their age, weight, and fitness goals.
- Workout Program Builder: Enable trainers to design custom training programs, add exercises, define sets, reps, and rest times, then assign these to specific students.
- Centralized Exercise Database: Provide a searchable database of exercises, categorized by body part (e.g., chest, back, legs), for trainers to use in program creation.
- Student Workout Logger: Allow students to view their assigned workouts and log their performance data (completed sets, reps, weights, and rest times).
- Progress Tracking Visualizer: Display visual charts for weight tracking and strength progression over time for both trainers and students.
- Basic Notification System: Implement essential notifications to alert students about new assigned workouts and trainers when students complete workouts.
- AI Workout Plan Suggestion Tool: An AI tool that suggests initial workout plan ideas or exercise recommendations to trainers based on a student's profile (goals, age, weight).

## Style Guidelines:

- Primary color: A dynamic, deep blue-green (#29A37A) to evoke growth and vitality, contrasting clearly against light backgrounds.
- Background color: A subtle, desaturated light green-grey (#F0F5F3) for a clean and professional aesthetic, enhancing readability.
- Accent color: A vibrant, clear green (#30E84E) to highlight interactive elements, calls to action, and key data points, creating visual emphasis.
- Body and headline font: 'Inter' (sans-serif) for its modern, neutral, and highly readable qualities, suitable for clear data presentation and user interfaces.
- Utilize clean, modern line icons that are easily recognizable and directly relate to fitness activities, measurements, and coaching actions.
- Implement a structured, dashboard-oriented layout with clear content hierarchy. Ensure responsive design for seamless user experience across devices.
- Incorporate subtle, smooth transitions for navigations, data updates in charts, and form submissions to enhance perceived performance and user interaction.
